# Build Notes 1.1.0

## Summary

- Restructured the repository: web source in `web/`, Android WebView wrapper in `Android/`, one `VERSION` file at the root.
- The Android app now bundles the single-file web build as `assets/index.html`, built by Gradle from `web/`.
- Added CI (`ci.yml`) for version checks, the single-file build and the debug APK, with GitHub releases on `v*` tags.
- Added `pages.yml` to deploy the web app to GitHub Pages on every push to `main`.
